# WOWBAGGER — 悪口と、結晶を。

**[ブラウザで遊ぶ](https://ks250206.github.io/Wowbagger-the-Game/)**

不死身のワウバッガーになって、宇宙の住民にアルファベット順で悪口を言って回るゲームです。今回は、**LGPS（Li₁₀GeP₂S₁₂）の結晶模型も、一人に一つ**。悪口を言うだけでは終わりません。模型を手渡して、次の名前へ向かいましょう。

PC・スマートフォンのブラウザで遊べます。インストールは不要です。

## あらすじと船内独白

初回表示では、ワウバッガーの旅の始まりを**4場面のグラフィック付きイントロ**で描きます。「不運な事故」「永遠の午後」「壮大で迷惑な計画」「本日の追加用件」を、アニメーションと文章でたどります。

イントロはスキップしてすぐに出発できます。画面右上の「?」から「グラフィック付きのあらすじを見る」を選ぶと、いつでも再生できます。

訪問前には、宇宙船の操縦席で相手の資料を確認します。**12種類の住民それぞれに固有の人物資料と、4章の一人称の独白**を用意しました。独白は字幕として表示され、章に合わせて窓の景色やホログラムが変わります。

| 船内の章 | 確認すること |
| --- | --- |
| 航路と所在地 | 恒星系、惑星、大陸、国、都市、住所 |
| 種族と性格 | 種族、肩書き、性格、本人のひとこと |
| 経歴と家族 | 経歴、家族の人数と構成 |
| 今日の用件 | 悪口と模型の配達条件、模型在庫 |

独白は「全文表示」でまとめて読めます。章を選び直したり、独白を飛ばして出発したりすることもできます。

## 遊び方

1. **船内で次の住民を確認し、訪問する。** 所在地・種族・性格・経歴・家族を確認して出発。通常航行は確実に到着します。無茶なワープは早いものの、時空事故で数百年を失うことがあります。
2. **こだわりに刺さる悪口を選ぶ。** 相手の話を聞き、3つの悪口から一つを選択。「観察」で追加のヒントを得られます。
3. **LGPS模型を手渡す。** 悪口と模型がそろって初めて配達完了。模型がなくなったら、船内プリンターで補充できます。補充には8年かかります。
4. **6人に配ったら、次の宙域へ。** 名簿は先へ続きます。配達している間にも、宇宙の人口は増えています。

住民は官僚、詩人、インフルエンサー、研究者など12種類。第1・第2宙域で6種類ずつ登場し、その先は組み合わせが変わります。相手に合う悪口で得点とコンボを伸ばすと、配達後の称号も変化します。

### 永遠との付き合い方

- **ゲームオーバーはありません。** 航行事故でも再生しますが、年月を失います。
- 退屈が限界に達すると、千年間の休眠に入って復帰します。
- 模型切れでも、その場で補充して配達を続けられます。
- 進行は、そのブラウザの `localStorage` に自動保存されます。別の端末・ブラウザ・公開先とは共有されません。
- 効果音は画面右上でオン／オフを切り替えられます。

## ローカルで動かす

HTML・CSS・JavaScriptだけで動く、ビルド不要のゲームです。外部ライブラリや外部画像の読み込みはありません。

リポジトリのルートで次を実行します。

```bash
python3 -m http.server 8000 --directory docs
```

ブラウザで <http://localhost:8000/> を開いてください。ES Modulesを使っているため、`index.html` をファイルとして直接開くのではなく、HTTPサーバーを経由します。

### 検証

Node.jsとnpmを利用できる環境で実行します。依存パッケージのインストールは不要です。

```bash
npm run check
```

JavaScriptの構文に加え、次のゲーム状態遷移を確認します。

- 悪口だけでは配達完了にならず、模型を渡して初めて記録されること
- 二重贈呈ができないこと、模型切れから補充して再開できること
- 途中保存と復帰、破損した保存データの扱い
- アルファベット順の継続、宙域の切り替え、住民の生成
- ワープ事故後の復帰、退屈による休眠からの復帰
- 12種類の人物資料・家族人数・4章の独白の整合性
- 人物資料を持たない旧版の保存データからの進行引き継ぎ

## LGPS模型について

ゲーム内の模型は、**Li 10個・Ge 1個・P 2個・S 12個の組成と、GeS₄・PS₄の四面体配位を示す模式模型**です。実際の単位格子、結晶座標、Ge/Pの混合占有は再現していません。結晶構造解析用のデータではありません。

LGPSの原著論文：N. Kamaya et al., “A lithium superionic conductor,” *Nature Materials* **10**, 682–686 (2011). <https://www.nature.com/articles/nmat3066>
